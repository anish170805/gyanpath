This folder contains section-by-section Markdown instructions extracted from the uploaded project report's structure.

## Use order
1. Read `00_MASTER_REPORT_RULES.md`.
2. Put actual project material in the referenced `<PROJECT_ROOT>/project-source/`.
3. Complete each section file using verified project facts.
4. Add images into `assets/` and keep image placeholders until the final assets are available.
5. Generate List of Figures, List of Tables, Index, and Table of Contents after the body is substantially complete.
6. Finalize page numbers only after assembling the DOCX/PDF.

The instructions intentionally preserve the report's structure rather than copying the sample project's subject matter.
