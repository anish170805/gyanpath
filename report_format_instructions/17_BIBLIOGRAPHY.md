# Bibliography Instructions

## Required format
Heading: `BIBLIOGRAPHY`

Use category headings, following the source structure:

```text
Books
1. <Book Title>
   <Author(s)>.

2. <Book Title>
   <Author(s)>.

Online Resources
1. <Resource Name>.
2. <Resource Name>.
3. <Resource Name>.
```

## Rules
- Keep bibliography separate from references.
- Books should contain actual title and author information.
- Online resources should represent broader background resources.
- Do not duplicate the entire references section blindly.
- Do not fabricate books or papers.

## Project-folder instruction
Use only real materials recorded in `<PROJECT_ROOT>/project-source/`.
