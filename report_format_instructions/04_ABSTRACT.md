# Abstract Instructions

## Required order
1. Heading: `ABSTRACT`
2. `Title: <PROJECT TITLE>`
3. `Description:`
4. One or more paragraphs covering:
   - what the system is,
   - the main problem it addresses,
   - key users/actors,
   - major features/modules,
   - AI/technical functionality where relevant,
   - security/access control where relevant,
   - technologies or implementation contribution,
   - expected or achieved value.
5. `Hardware Requirements:`
6. Bullet list of hardware.
7. `Software Requirements:`
8. Bullet list of software.
9. Student/project details if required by the same sample:
   - Name
   - College Name
   - Branch
   - Semester
   - Mobile Number

## Content rules
Do not turn the abstract into a chapter. It is a compact system overview plus requirements.

## Project-folder instruction
Read actual stack, modules, hardware requirements, and software requirements from `<PROJECT_ROOT>/project-source/`.
