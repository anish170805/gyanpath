# References Instructions

## Required format
Heading: `REFERENCES`

Use a numbered list.

Source format pattern:

```text
1. <Resource / Documentation Title>.
   <Short description of what it is>.
   Available at: <URL>

2. <Resource / Paper / Documentation Title>.
   <Short description>.
   Available at: <URL>
```

## Rules
- Include sources actually used for the project or report.
- Prefer official documentation for technologies.
- Include research papers, standards, or technical documentation where genuinely used.
- Do not add URLs that were not consulted.
- Keep numbering continuous.

## Project-folder instruction
Collect references from citation/source notes stored in `<PROJECT_ROOT>/project-source/` or the research log. Do not invent references just to make the list longer.
